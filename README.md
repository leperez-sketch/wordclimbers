# 🏔️ EFL Word Climbers - Split Screen Smartboard Game

¡Bienvenido a **EFL Word Climbers**! Un juego interactivo de pantalla dividida diseñado especialmente para pantallas inteligentes (Smartboards, Promethean, SMART Board) en aulas de inglés (EFL/ESL).

---

## 🚀 Cómo publicar en GitHub Pages (Paso a Paso)

1. **Descomprime** este archivo ZIP.
2. Ve a [GitHub.com](https://github.com) y crea un nuevo repositorio (ej. `word-climbers`).
3. Sube los 5 archivos (`index.html`, `styles.css`, `script.js`, `questions.json`, `README.md`).
4. En **Settings -> Pages**, activa la rama `main` y guarda los cambios.
5. Abre la URL generada en tu pantalla táctil.
